sitegrabber
Docs GitHub

Download entire websites.

One command. Grabs every page, every asset. Rewrites all links to work offline. Open it in a browser or deploy anywhere.

Install
$ curl -fsSL https://sitegrabber.dev/install | bash
Then grab a site
$ sitegrabber https://example.com

Fast

Async downloads with configurable concurrency. Crawls sites in seconds, not minutes.

Complete

HTML, CSS, JS, images, fonts, videos. Extracts URLs from href, src, srcset, CSS url(), @import.

Works offline

All links rewritten to relative paths. Open index.html directly or serve with any static file server.

Single binary

No runtime, no dependencies. One 6MB binary. Install in 5 seconds, works everywhere.

Deploy anywhere

Output is a clean static directory. Push to Cloudflare Pages, Netlify, GitHub Pages, or any server.

Configurable

Control depth, concurrency, timeout, user-agent. Include subdomains or grab assets only.

Usage

# Download a site
sitegrabber https://example.com

# Custom output directory
sitegrabber https://example.com -o my-mirror

# Limit depth, boost concurrency
sitegrabber https://docs.example.com -d 5 -c 16

# Include subdomains
sitegrabber https://example.com --include-subdomains
