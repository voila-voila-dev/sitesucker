Every option explained. Sitegrabber is a single command with sensible defaults — most of the time you just need the URL.

Quick start

# Install
curl -fsSL https://sitegrabber.dev/install | bash

# Download a website
sitegrabber https://example.com

# Open it offline
open example.com/index.html

Required

URL positional argument
required

The starting URL to crawl. Must include the protocol (https:// or http://). The crawler will discover and download all pages and assets on the same domain, starting from this URL.

sitegrabber https://docs.example.com

Output

--output -o <DIR>
default: domain name

Directory where downloaded files are saved. If not set, a directory named after the domain is created in the current folder (e.g. example.com/). The directory is created automatically if it doesn't exist.

sitegrabber https://example.com -o ./my-mirror
--warc
default: off flag

Save a WARC/1.0 archive file alongside the regular file output. The WARC file contains the raw HTTP responses and is useful for web archival, compliance, or replay with tools like replayweb.page. The archive is saved in the output directory as <domain>-<timestamp>.warc.

sitegrabber https://example.com --warc

Crawl behavior

--depth -d <N>
default: 25

Maximum link depth to follow from the starting URL. Depth 1 downloads only the starting page and its direct assets. The default of 25 is effectively unlimited for most sites. Lower it to crawl just a section of a large site.

# Only the homepage and one level of links
sitegrabber https://example.com -d 2
--concurrency -c <N>
default: 8

Number of parallel downloads. Higher values speed up crawling but put more load on the target server. Combine with --delay to be polite while still downloading efficiently.

sitegrabber https://example.com -c 16
--delay <MS>
default: 100 milliseconds

Minimum delay in milliseconds between requests per download task. Acts as a rate limiter to avoid overwhelming the server. Set to 0 for maximum speed (local testing, your own sites). Each concurrent task waits independently.

# Be polite — 500ms between requests
sitegrabber https://example.com --delay 500

# No delay for your own site
sitegrabber https://localhost:3000 --delay 0
--timeout -t <SECS>
default: 30 seconds

HTTP request timeout for each individual request. If a page or asset takes longer than this to respond, it is skipped. Increase for slow servers or large files.

sitegrabber https://slow-site.com -t 60
--include-subdomains
default: off flag

Also crawl and download pages on subdomains of the target. For example, if you crawl example.com, this will also follow links to blog.example.com, docs.example.com, etc. Assets on subdomains are always downloaded regardless of this flag.

sitegrabber https://example.com --include-subdomains
--assets-only
default: off flag

Only download assets (CSS, JS, images, fonts, etc.) referenced by crawled pages. Pages themselves are downloaded but the crawler won't follow links to discover new pages. Useful if you just need the assets from a known set of pages.

sitegrabber https://example.com --assets-only
--respect-robots
default: off flag

Fetch and obey the site's robots.txt rules. When enabled, sitegrabber checks disallow/allow rules for its user-agent before crawling each URL. Also parses sitemap references from robots.txt to discover additional URLs.

sitegrabber https://example.com --respect-robots
--user-agent <STRING>
default: SiteGrabber/1.0

Custom User-Agent header sent with every request. Some sites serve different content based on the user-agent, or block unknown bots. Use a browser user-agent string if the site blocks the default.

sitegrabber https://example.com --user-agent "Mozilla/5.0 (compatible; MyCrawler)"

Filtering

--exclude <PATTERN>
repeatable glob syntax

Skip URLs matching the given glob pattern. Can be specified multiple times to exclude multiple patterns. Useful for skipping admin pages, search results, or large file directories. Patterns are matched against the full URL.

# Skip all PDF files and the admin section
sitegrabber https://example.com --exclude "*.pdf" --exclude "*/admin/*"

# Skip query strings
sitegrabber https://example.com --exclude "*?*"
--max-size <SIZE>
optional supports KB, MB, GB

Stop downloading after the total size of all downloaded content exceeds this limit. Accepts human-readable sizes: 50MB, 1.5GB, 512KB, or plain bytes. Useful for capping bandwidth usage or storage.

# Stop after downloading 100MB
sitegrabber https://large-site.com --max-size 100MB

Resume

--no-resume
default: off (resume is enabled) flag

By default, sitegrabber keeps a .sitegrabber-state file in the output directory tracking which URLs have been downloaded. If the crawl is interrupted, re-running the same command resumes where it left off. Use --no-resume to force a fresh crawl from scratch, ignoring any existing state.

# Force re-download everything
sitegrabber https://example.com --no-resume

Verbosity

--verbose -v
flag

Log every request with status code, URL, and file size. Useful for debugging which pages are being downloaded and spotting errors. Cannot be used together with --quiet.

sitegrabber https://example.com -v
--quiet -q
flag

Suppress all output except errors. No progress bar, no summary. Useful for scripts and CI pipelines. Cannot be used together with --verbose.

sitegrabber https://example.com -q

Examples

# Basic site download
sitegrabber https://example.com

# Mirror a docs site with fast settings
sitegrabber https://docs.example.com -c 16 --delay 0 -o docs-mirror

# Archive a site with WARC output
sitegrabber https://example.com --warc -o archive

# Polite crawl respecting robots.txt
sitegrabber https://example.com --respect-robots --delay 500

# Shallow crawl, skip large files
sitegrabber https://example.com -d 3 --max-size 50MB

# Exclude patterns
sitegrabber https://example.com --exclude "*.pdf" --exclude "*/tag/*"

# Resume an interrupted crawl
sitegrabber https://example.com -o my-site
# (just run the same command again)

# Include subdomains + verbose
sitegrabber https://example.com --include-subdomains -v
